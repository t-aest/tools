# 工具箱仓库 (Toolbox)

一个收集我开发的各种实用小工具的仓库。这里既有日常工作需要的效率工具，也有学习新技术时做的有趣项目。

---

## 工具列表

### 1. Markdown 文档阅读器 (Markdown Reader)
一个完全在浏览器中运行的本地 Markdown 文档阅读器，无需任何安装，支持文件夹拖拽、目录树导航、代码高亮等功能。

#### 功能特点
*   **现代化界面**：类 VS Code 的深色侧边栏设计，视觉舒适。
*   **便捷导入**：支持文件夹拖拽或直接选择本地文件夹。
*   **主题切换**：支持浅色/深色双主题，适应不同环境。
*   **代码高亮**：内置语法高亮，阅读代码更清晰。
*   **代码复制**：代码块一键复制功能。
*   **自动目录**：根据文档标题自动生成右侧目录（TOC）。
*   **纯前端**：无需后端服务，完全离线，保护隐私安全。
